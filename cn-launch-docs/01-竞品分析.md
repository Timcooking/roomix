## 一、结论摘要（5 条，先说坏消息）

1. **大陆没有"先配人、再一起刷房"的完整闭环竞品**，但"找室友"作为**功能入口已普遍存在**（Wellcee、巴乐兔、自如、优区生活、闲鱼、豆瓣、小红书都有）。差异化必须靠**闭环 + 可解释契合度**，而不是"我们想到了找室友"这个概念。
2. **⚠️ "全球首创室友契合度算法"这个表述不成立，必须改掉。** 已有成熟先例：Roomi（问答 + 算法配对）、ideal flatmate（20 questions）、CoHabby（**14 题 6 类**算可解释 Synergy Score）、iROOMit（AI 匹配）、Diggz / RoomSync / BeRoomie（滑动匹配）。
   - **建议改为**："**首个把可解释契合度用于双人共同的房源决策**"。
3. **"双人共同决策房源"未检索到直接先例**——最接近的是 BunkUp（"和室友一起找新公寓"）与 SpareRoom 的品牌语 *Find Home Together*（是 slogan 不是功能）。**这是目前最可信的护城河假设。**
4. **大陆监管环境在 2025 年发生质变**，直接决定上线前必须补的能力：《住房租赁条例》2025-09-15 施行（房源信息须真实、**经纪机构不得代收代付租金押金**、不得无正当理由扣押金）、《人脸识别技术应用安全管理办法》2025-06-01 施行（人脸不得作为唯一验证方式）、算法推荐须公示原理并提供关闭项。已核实：[住房租赁条例全文](https://www.mohurdic.org.cn/gk/zdzc/art/2025/art_146a71c4c3c6448489a98749d8e644e4.html)，国务院 2025-07-16 公布。
5. **信任与核验是全行业公认短板**（也正是我们本地化设想要攻的地方）：Roomster 被 FTC 与 6 州起诉发布假好评、虚假房源（2022-08）；Flatmates.com.au 在 Trustpilot 仅 **1.3/5**（5470 条评价）；58 同城被指虚假房源低价引流（2026-04）；小红书租房骗局被驻外使馆点名。

### 4.1 行业普遍缺失 = 我们的机会【推断】

1. **"人配好之后一起决策房"的闭环**——所有人都在"先找房"或"先找室友"里二选一。
2. **契合度分数的可解释性**——大厂不做分数，做分数的小玩家没有房源与核验。
3. **室友身份验证与房源核验的绑定**（"这个人可信 + 这套房真实"同时成立）——**这一条正是你提的本地化设想在竞品坐标系里的准确位置**。
4. **签约/押金环节**：撮合平台普遍不介入，纠纷外部化（Flatmates 1.3★、小红书骗局、58 低价引流）。
5. **女性 / 性少数安全筛选与响应机制**（Wellcee 已有 LGBTQ 标签，说明需求真实存在）。
6. **多人（≥3 人）合租的组内共识**：全部产品都是 1v1 或纯列表。

## 五、交互范式对比

| 范式 | 证据与先例 | 对我们的判断【推断】 |
| --- | --- | --- |
| **卡片滑动** | 优点：双向同意显著减少骚扰信息（"没人能在双方都表达兴趣前给你发消息"）。缺点同样明确：**一张照片看不出作息、清洁标准、过夜访客**；一次租约 ≈ 8760 小时共处，**滑动错配的代价远高于一次约会**。先例：Diggz（"Tinder for roommates"）、RoomEasy、RoomSync（高校"右滑喜欢"）、BeRoomie（滑动 + 契合度分数）。**反例：市场第一的 SpareRoom 至今不用滑动**，而是"列表 + Filter/Sort/Map + Hide/Save" | **滑动只用于"人"**；房源一律列表/地图/筛选，不做"房源也滑"。⚠️ 这与全球版"一起刷房"的卡组形态**直接冲突**，见下方专段 |
| **问卷 → 契合度** | 先例充分：Roomi 问答算法、ideal flatmate 20 questions、CoHabby 14 题 6 类、iROOMit AI、Hinge prompts、Soul 兴趣匹配。学界还发现**学生更喜欢"视觉化互动测试"而非长问卷**，并存在"问卷疲劳"风险 | 10 题保留，但把每题做成可滑/可点的**图形化控件**；给出"分数由哪些题贡献"的解释层。借鉴 CoHabby 的免责表述："**是话题起点，不是预测**" |
| **双人共同决策** | **未检索到直接先例**。最接近：BunkUp（和室友一起找新公寓）、SpareRoom 的 slogan *Find Home Together*（非功能）、巴乐兔"情侣找房"入口（截图可见） | **这是我们最可防御的交互资产**，应尽早申请外观/交互专利，并做成可命名的品牌功能（如"一起刷房"） |
| **大陆用户既有习惯** | 地图找房 + 条件筛选表单 + 列表是主路径：自如"位置/户型/租金/租期/入住时间"、巴乐兔"地图找房"、贝壳"地图找房 + 智能找房 + VR 看房"、安居客"地图搜房"；VR/MR/AI 找房被贝壳 2026 住博会主推；直播看房有独立产品（抖房）；小红书路径是"笔记 → 评论/私信 → 加微信 → 线下看房" | "房源卡组"**必须能一键切到地图视图**，且"预约看房"要落到线下动作，否则"只能刷卡"会被理解为"信息不足" |

### 5.1 一个必须现在决定的交互冲突

竞品证据（SpareRoom 用列表且市占第一、BeRoomie 用滑动 + 分数但评分 1.8★）指向"房源不适合滑动"；而我们的核心亮点恰恰是**房源卡组 + 双人同时滑**。

**【推断】折中方案**：保留"一起刷房"作为**配对之后的决策仪式**（它的价值是"两人当面对齐偏好"，不是"高效找房"），但把它明确定位为**决策工具而非浏览工具**：
- 配对前 / 未配对 → 房源用**列表 + 地图 + 筛选**（对应大陆版新增的房源发现流）；
- 配对后 → 提供"一起刷房"作为**收敛工具**（从 20 套候选里 3 分钟达成共识），并在卡组里只放**双方条件都过筛**的房源。

这样既不与用户习惯对抗，又保住独占交互。（与 [02 文档第 1 节](./02-中国大陆功能设计与全球版差异.md) 的"双入口"改动是同一个决策的两面。）

## 七、结论

### 7.1 必须在大陆上线前补上的差距（按优先级）

1. **房源真实性与身份双核验**：至少做到"房源地址可核验 + 发布者实名/人脸 + 房源图片审核"。依据：自如 2016 年已用人脸识别、贝壳有真房源四要素、SpareRoom 人工审核每条广告；反面是 Roomster 被 FTC 起诉、58/小红书骗局。**没有这一条，"踩坑/中介冒充房东"的痛点叙事不成立。**
2. **合规三件套**：①《住房租赁条例》（2025-09-15 施行）要求房源信息真实准确完整、**经纪机构不得代收代付租金押金**、无正当理由不得扣减押金（违者 2 万–10 万罚款）；②《互联网信息服务算法推荐管理规定》要求**公示算法原理/目的/主要运行机制**并提供**关闭算法推荐的选项**，我们的"契合度百分比"属个性化推送/排序决策类，需评估算法备案；③《人脸识别技术应用安全管理办法》（2025-06-01 施行）要求**人脸验证不得作为唯一验证方式**。
3. **安全与信任运营**：一键举报、封禁、骚扰词过滤、线下看房前的"公共场合见面"引导、女性/性少数专属筛选（参考 Bumble/Tinder 的验证徽章与"双向同意才能私信"）。
4. **地图视图 + 条件筛选 + 预约看房**：补齐大陆用户既有找房路径。
5. **变现与交易闭环的最小版本**：明确谁付费。建议 **租客侧免费 + 房东/公寓方付费曝光 + 增值 Boost**——避开优区生活"联系就要钱"与 Flatmates"回复也要钱"引发的差评；至少提供电子签约/押金规则的**信息层**，**不自建资金池**以规避代收押金红线。

### 7.2 竞品短期抄不动的护城河假设

1. **"配对 → 双人共同刷房 → 双方点头 → 预约看房"的闭环交互**（未检索到先例）。它要求同时具备"人的匹配"和"房源决策"两套资产：**房源平台不愿做社交，社交平台没有房源核验**——组织与供给侧壁垒 > 代码壁垒。
2. **契合度分数 × 房源决策结果的联合数据资产**：每一次"两人一起否掉/接受某套房"都是**偏好共现数据**，可训练"双人决策预测"，这是单侧问卷产品（Roomi/CoHabby）和纯房源平台都拿不到的样本。
3. **三语 + 跨城 + 留学生/新移民人群的冷启动组合**：Wellcee 已验证"170 国用户 + 多语言"在中国大陆可行，但它是内容社区而非双人闭环；我们以 HK 为演示场切入跨境人群（Homates/Homester 均为小体量免费站点），**窗口期约 12–18 个月**【推断】。

### 7.3 需要修正的两个原始假设（重要）

| 原假设 | 修正后表述 |
| --- | --- |
| "全球首创室友契合度算法" | → **"首个把可解释契合度用于双人共同的房源决策"**（Roomi / CoHabby / ideal flatmate / Diggz 已占位，融资材料与演示稿都需改） |
| "豆瓣 / 蘑菇租房等作为活跃对标" | → 二者均已退出或僵尸化。**报告与融资材料改用 5 个活对标：Wellcee · 自如 · 贝壳 · 小红书 · SpareRoom** |
