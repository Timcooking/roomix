## 1. 一句话差异

| | 全球版（香港基线） | 中国大陆版 |
| --- | --- | --- |
| 核心价值 | **先滑到人，再一起滑到房**——把"生活习惯"变成可见信息 | **先证明你是真人，再谈合不合适**——把"信任"做成可见的产品层 |
| 决策入口 | 单一流程（测评 → 室友卡组 → 一起刷房） | **双入口**：我有房缺室友 / 我要找房缺室友 |
| 冷启动约束 | 房源由平台侧统一格式整理，演示不暴露供给问题 | 真实供给稀缺，房源不能锁在"配对之后" |
| 合规负载 | 几乎为零（演示站、虚构数据） | **重**：实名、年龄、人脸、算法备案、房源核验、内容审核（详见 04 文档第 5 节） |

**【设计】最关键的结构性改动只有一处**：全球版把"房源"tab 做成**配对后的奖励**（未配对时显示门控空状态"先找到室友，再一起刷房"，源码 [src/screens/Rooms.tsx:19-43](file:///d:/Agent/Roommix/src/screens/Rooms.tsx#L19-L43)）。中国大陆版必须把房源从"奖励"改成"**入口 + 奖励**"两种形态并存——否则在没有真实房源供给与用户密度的第一个月里，产品没有可浏览的内容。"一起刷房"仍然是核心亮点与最终转化路径，只是不再是唯一的房源可见方式。

### 2.2 改造（同一功能，不同口径）

| 功能 | 全球版口径【事实】 | 大陆版口径【设计】 | 改的理由 |
| --- | --- | --- | --- |
| 预算题 | `HK$6,000 以下 / 6–9k / 9–12k / 12k+` | `¥1,500 以下 / 1,500–3,000 / 3,000–4,500 / 4,500+`（可按城市动态分档） | 人民币 + 单间合租价格带；且需支持"北京/上海档"与"杭州/成都档"不同 |

## 4. 导航栏设计

### 4.1 全球版现状【事实】
四标签：`室友 / 房源 / 消息 / 我的`（[src/App.tsx:116-121](file:///d:/Agent/Roommix/src/App.tsx#L116-L121)），选中态用品牌 Logo 渐变，`房源` 有配对时显示圆点、`消息` 有配对数时显示数字角标（[src/App.tsx:151-156](file:///d:/Agent/Roommix/src/App.tsx#L151-L156)）。

### 4.2 大陆版方案【设计】：**保留 4 个 tab，不加第 5 个**

理由：第 5 个 tab 会稀释"先人后房"的叙事；新增能力（认证、筛选、安全）应沉进"我的"与顶部工具位，而不是抢导航位。

| 顺序 | tab | 简中 | 图标 | 角标逻辑（大陆版） | 与全球版的差别 |
| --- | --- | --- | --- | --- | --- |
| 1 | `discover` | **找室友** | 品牌 Logo（选中态渐变） | 新配对数 | 名称从"室友"改为动词化"找室友"，符合大陆用户搜索习惯【设计】 |
| 2 | `rooms` | **房源** | IconRooms | 有可通勤匹配的房源时显示"1"点；未配对时**不再显示门控**，而是显示"看看附近的房" | **改造为双入口**（本文最大改动） |
| 3 | `chats` | **消息** | IconChat | 未读数（含系统安全通知） | 新增"系统/安全"会话置顶 |
| 4 | `me` | **我的** | IconPerson | **未认证时显示"去认证"红点** | 认证中心、隐私与推荐设置、安全中心都挂这里 |

顶部工具位（页面内，不进导航）：`找室友` 页 = 城市切换 + 筛选（P0 实装）；`房源` 页 = 视图切换（卡组 ⇄ 通勤地图）。

### 4.3 一级入口之外的"任务型入口"【设计】
大陆版首次进入需要一次**意图分流**（不是导航，是 onboarding 的第 0 步）：

```
你现在的状态是？
  A. 我已经有房，缺室友      → 直接进"房源→室友"支线（发布我的房 / 招募）
  B. 我要找房，也缺室友      → 标准支线（测评 → 找室友 → 一起刷房）
  C. 我先看看房源            → 房源支线（浏览 → 对某间房发起"找同租"）
```
这一步是解决"房源不能锁在配对之后"的最小代价方案：保留 B 作为默认与主打演示路径，同时让 A/C 有路可走。

### 5.1 与全球版 IA 的三处结构性差异（对比 [00 文档第 6 节](./00-全球版（香港基线）产品现状.md)）

1. **新增"启动/授权层"**：全球版从欢迎页直接进测评，无任何账号概念；大陆版在进入卡片流之前必须完成登录 + 实名 + 年龄核验（法规前置，非产品选择）。
2. **新增"意图分流"与"房源发现流"**：把全球版的单一线性漏斗改成三入口，房源 tab 从门控变为可达。
3. **"我的"从设置页升级为信任中心**：全球版的"我的"只有卡片/答案/语言/重置四项【事实】[src/screens/Me.tsx:19-58](file:///d:/Agent/Roommix/src/screens/Me.tsx#L19-L58)；大陆版的"我的"承载认证中心、粒度控制、推荐设置、安全中心四个新模块——这是"对面不是骗子"的产品化落点。

## 6. 本地化口径速查（给写文案与改数据的人）

| 维度 | 全球版【事实】 | 大陆版【设计】 |
| --- | --- | --- |
| 货币 | `HK$` + `toLocaleString('en-US')`（[src/data/rooms.ts:201](file:///d:/Agent/Roommix/src/data/rooms.ts#L201)） | `¥` + 千分位；"每人每月"表述改为"**单间月租**" |
| 面积 | `呎`（ft²） | `㎡`；并区分"建筑面积/使用面积" |

| 楼层 | `5 楼 / 中层 / 高层` | 保留，但增加**有无电梯**（大陆"步梯房"是硬指标） |

| 来源 | 业主直租 / SquareNest / HomeHub HK / Spacebox | 房东直租 / 已核验中介 / 长租公寓 / 转租（含发布方实名与核验状态） |
| 人物职业 | `UX 设计师 @ 鲗鱼涌`、`港大研究生` | `腾讯 · 深圳企鹅岛 · 产品经理`、`字节跳动 · 地推 BD`、`华南师范大学 · 在读`（配徽章与粒度） |
| 语气 | 港式粤语（繁中）、fwb 梗 | 简中口语 + **不使用软色情/擦边类比**；安全与信任词汇前置 |

## 8. 落地风险与取舍（提前说清）

| 风险 | 严重度 | 应对 |
| --- | --- | --- |
| **备案周期**：App 备案（30 个工作日级）+ 算法备案 + ICP/增值许可，是"上线时间"的真正瓶颈，不是开发 | 高 | 备案与开发并行启动；演示用海外域名，正式版走境内 CDN |
